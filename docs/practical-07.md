## 3. Problem Definition
Client-side JavaScript validation is designed solely for user experience and can be disabled or bypassed by malicious actors sending raw HTTP requests. Robust web systems must implement authoritative server-side validation to sanitize incoming payloads, eliminate script injection (XSS), verify business rules, and ensure reliable data persistence.

## 8. Viva Voce Questions & Answers

### Q1: What is the superglobal `$_POST` in PHP?
**Answer:** `$_POST` is an associative array in PHP containing variables passed to the current script via the HTTP POST method using `Content-Type: application/x-www-form-urlencoded` or `multipart/form-data`.

### Q2: Why is `filter_var($email, FILTER_VALIDATE_EMAIL)` preferred over manual string checks?
**Answer:** `filter_var()` with `FILTER_VALIDATE_EMAIL` rigorously tests the string against RFC 822 / RFC 5322 email specifications, ensuring robust detection of malformed email addresses.

### Q3: What is the purpose of `htmlspecialchars()`?
**Answer:** `htmlspecialchars()` converts special HTML characters (`&`, `<`, `>`, `"`, `'`) into their corresponding HTML entities (`&amp;`, `&lt;`, etc.), preventing Cross-Site Scripting (XSS) attacks when echoing user data back into the HTML response.

### Q4: How does `file_put_contents()` work with JSON storage?
**Answer:** `file_put_contents($path, json_encode($data, JSON_PRETTY_PRINT))` serializes PHP associative arrays into structured JSON formatted text and atomically writes it to the designated disk file.

### Q5: Why is `password_hash()` used even in flat-file storage?
**Answer:** Plaintext passwords must never be stored anywhere, whether in flat files or relational databases. `password_hash($password, PASSWORD_DEFAULT)` uses strong one-way adaptive cryptographic hashing algorithms (BCRYPT) with automatic salt generation to protect user credentials against data leaks.
