CS201: Web Development - Course Overview

Faculty: Prof. Dhara | Credits: 4 | Semester: 3

Syllabus & Course Modules

  1. Module 1: Web Architecture, HTTP/HTTPS, URLs, and HTML Processing.
  2. Module 2: Page Layouts, CSS Flexbox/Grid, and Responsive Design.
  3. Module 3: JavaScript DOM Manipulation, Event Handling, LocalStorage, and Dynamic UI Components.
  4. Module 4: Version Control with Git, GitHub Repository Workflows, and READMEs.
