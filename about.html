About StudentHub

Learn about our mission, design philosophy, and academic framework powering student engagement at CHARUSAT.

Our Vision & Purpose

StudentHub was conceptualized and engineered for the course ITUE203: Web Development Frameworks (3rd Semester B.Tech Computer Science Engineering) to bridge the digital gap between university students, student club coordinators, and campus administrators.

By replacing fragmented communication tools with a single accessible, responsive, and secure web application, StudentHub empowers students to stay informed on technical hackathons, guest seminars, co-curricular workshops, and official university notices.

Key System Objectives

🎯 Centralized Campus Communication

Eliminate conflicting announcement boards and lost spreadsheet registrations by unifying event discovery, registrations, and participant validation in a single relational database.

🔒 Enterprise-Grade Security Standards

Protect student credentials using modern bcrypt hashing, session regeneration, input sanitization, and strict Role-Based Access Control (RBAC).

⚡ High-Performance Asynchronous UI

Deliver swift user experiences using standard JavaScript Fetch APIs, modular styling, and lightweight server-side PHP processing without unnecessary heavy frameworks.

♿ Universal Accessibility (WCAG 2.1 AA)

Ensure that all students, including those utilizing screen readers or keyboard navigation, experience seamless usability with semantic HTML5 landmarks and accessible form controls.

Target User Roles & Stakeholders

1. University Students

Browse upcoming workshops, submit event registrations with instant confirmation, maintain personal academic profile details, and provide campus feedback.

2. Event Coordinators & Faculty

Publish verified campus events, upload event posters, monitor registration rosters in real time, and export attendance records.

3. System Administrators

Oversee student account lifecycle, enforce role permissions, manage platform security, and audit system activity logs.

Academic Framework

This project is developed as a continuous 15-phase progressive web development project under the guidance of the Department of Computer Science & Engineering, Chandubhai S. Patel Institute of Technology (CSPIT), CHARUSAT.
